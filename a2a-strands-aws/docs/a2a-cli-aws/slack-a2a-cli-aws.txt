A Rust A2A 1.0 agent on Amazon Lightsail and a Strands A2A 0.3 agent on Amazon Bedrock AgentCore Runtime, plus localhost copies of both.
The same a2a CLI commands checked all four endpoints, 16 of 16 passed, and the Strands agent reaches the Rust agent by running that same CLI.
On AWS the only additions are a login token, a session header and the full agent card URL.
